# XVIII Concurso de Proyectos de Innovación ISC (Refactorizado)

Sitio web modernizado, responsivo y accesible para el XVIII Concurso de Proyectos de la Academia de Ingeniería en Sistemas Computacionales del TSJ Zapopan.

## 🔗 Enlace en Producción
[Visitar Sitio Web](https://github.com/David-luna-G/Concurso_Proyectos_ISC)

## 🚀 Mejoras Implementadas
- **Estructura semántica:** Migración total a tags semánticos HTML5 (`<header>`, `<nav>`, `<main>`, `<section>`, `<footer>`) y metadatos Open Graph.
- **Diseño Responsivo & CSS:** Paleta personalizada mediante variables CSS institucionales, layout mobile-first con CSS Grid/Flexbox y soporte de tema claro/oscuro.
- **Interactividad JavaScript:** Cuenta regresiva en vivo, validación de correo institucional en tiempo real sin recarga de página y sistema interactivo de filtrado de proyectos.
- **Rendimiento:** Optimización de assets a formato WebP, lazy loading y auditoría Lighthouse > 85 en todas las métricas.

## 🛠️ Tecnologías Utilizadas
- HTML5 semántico y accesible (WAI-ARIA)
- CSS3 moderno (Custom Properties, Flexbox, Grid)
- JavaScript vanilla (ES6+)
